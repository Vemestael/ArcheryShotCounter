# Security Policy

Archery Shot Counter is a personal hobby project — a Wear OS app with no network access
(no `INTERNET` permission), no backend, and no user accounts. Its attack surface is small,
but if you find a real security issue (not just a bug), please report it responsibly.

## Reporting a vulnerability

Email **vemestael@gmail.com** with details. Please don't open a public issue for anything
that could be exploited before a fix is out.

You can expect an acknowledgement within a few days. This is a solo-maintained hobby
project, so response times may vary, but reports are taken seriously.

## Supported versions

Only the latest release on the
[Releases page](https://github.com/Vemestael/ArcheryShotCounter/releases) is supported.
